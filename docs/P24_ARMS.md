Eight are generated by `agent/feedback/p23_feedback_replay.py` (audited via `agent/feedback/export_p23_rowlevel.py`), and two are generated by `agent/feedback/p24_conditional_repair.py` (audited via `agent/feedback/export_p24_rowlevel.py`):

## Reproduction Commands

```bash
python agent/feedback/p24_conditional_repair.py \
  --input data/feedback_replay/P23_INPUT_GROUPKEY_REPAIRED.csv \
  --models-dir models_and_configs/p22_feedback \
  --out /tmp/geoagent_p24 --mode retrospective

  --input data/feedback_replay/P23_INPUT_GROUPKEY_REPAIRED.csv \
  --models-dir models_and_configs/p22_feedback \
  --out /tmp/p24_rowlevel --compare results/per_row_predictions/PREDICTIONS_582.csv
```

## Equal-$K$ Budget Difference Note

`p24_conditional_repair.py` computes its internal equal-budget controls using its own accepted action count ($K=11$ in 2025, $K=4$ in 2026), whereas the authoritative Equal-$K$ columns in `PREDICTIONS_582.csv` and `results/equal_k_corrected_20261120/` use the full agent's accepted action count ($K=12$ in 2025, $K=2$ in 2026). Consequently, comparing `export_p24_rowlevel.py` against `PREDICTIONS_582.csv` matches 582/582 on `P24_CONDITIONAL` and `P24_GLOBAL_ABLATION`, and differs on exactly the expected 3 tail rows for the two internal Equal-$K$ columns.
